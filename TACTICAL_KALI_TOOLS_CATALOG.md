# Project Sentinel: Tactical Kali Linux-Style Offensive & Defensive Tool Catalog

> **Architectural Specification & Conceptual Roadmap**  
> *Target Environment:* Android ARM64 Host-Agent + C4ISR Admin Command Center + Encrypted WebSocket Telemetry Gateway.  
> *Scope:* Pure analysis, understanding, and architectural classification. **No implementation required.**

## I. RF, Wireless & Spectrum Intelligence (SIGINT / ELINT / COMINT)

### 1. Offensive Wireless Tools
* **Aircrack-ng / Wifite Suite Integration:**
  * **WPA2 PMKID Rogue Capture:** Passive and active capture of the 802.11 4-way handshake PMKID from AP Beacon/Association frames without waiting for a full client handshake.
  * **Automated WPS Pixie-Dust Engine:** Offline cryptographic brute-force on weak nonces generated by legacy Wi-Fi Protected Setup (WPS) routers within range.
  * **Hostapd-Mana / Rogue Captive Portal AP:** Spawns a software access point that mimics known SSIDs, supports KARMA and MANA attacks to lure nearby smartphones into associating, and serves custom phishing portals.
* **802.11 Frame Injection & Deauthentication:**
  * **Airgeddon / MDK4 Pulse Engine:** Targeted or broadcast 802.11 Deauth/Disassociation frame injection to force client re-association and capture handshakes.
  * **Beacon Flood Generator:** Broadcasts thousands of spoofed SSIDs per minute to confuse local Wi-Fi scanners and overwhelm surveillance dashboards.
* **BLE & Bluetooth Exploitation:**
  * **BtleJack / Mirage BLE Hijacker:** Sniffs, jams, and injects into existing active BLE connections, intercepting peripheral data (smart locks, fitness monitors, medical devices).
  * **BlueHydra / Spooftooph Bluetooth Spoofer:** Clones Bluetooth Classic and BLE MAC addresses, spoofing Class of Device (CoD) to impersonate trusted audio headsets or car kits.
  * **Apple AirTag / FindMy Stalker Emulator:** Spoofs rotating Apple cryptographic public keys to inject ghost AirTags into Apple's Find My network or track target physical perimeters.

### 2. Defensive Spectrum & Counter-Surveillance Tools
* **Kismet / Wi-Fi Deauth Radar:**
  * Monitors raw 802.11 frames to detect deauthentication storms, anomalous sequence numbers, and evil-twin APs spoofing the gateway's BSSID with different signal characteristics.
* **IMSI-Catcher (Stingray) & Fake BTS Radar:**
  * **Cellular Downgrade Detector:** Detects forced downgrades from LTE/5G to insecure 2G (GSM) or 3G protocols commonly enforced by Stingray and Hailstorm interception gear.
  * **Silent SMS (Type 0 / Ping) Watchdog:** Detects stealth SMS messages sent by law enforcement or intelligence agencies to triangulate device location without user notification.
  * **RRC Reject & Ciphering Indicator:** Alerts when base stations command the mobile modem to transmit with A5/0 (null ciphering) or spoofed TAC/MCC/MNC values.
* **BLE Tracker Sweeper (AirTag / SmartTag Hunter):**
  * Tracks persistent BLE advertisements from Apple AirTags, Samsung SmartTags, and Tile beacons that maintain continuous proximity across multiple GPS breadcrumb fixes.
* **Acoustic / Ultrasonic Counter-Intelligence:**
  * **Audio Infrasound / Ultrasound Jammer:** Emits masked high-frequency acoustic noise (20–22 kHz) to physically desensitize nearby unauthorized microphone diaphragms.

## II. Network Reconnaissance, Active Exploitation & MITM

### 1. Offensive Network & MITM Tools
* **Bettercap / Responder Suite:**
  * **LLMNR / NBT-NS / mDNS Poisoning:** Responds to local multicast/broadcast name requests on corporate or public Wi-Fi to capture NetNTLM hashes and redirect traffic.
  * **Rogue IPv6 DHCP/RA Server (mitm6):** Advertises rogue IPv6 DNS servers to take precedence over IPv4 DNS on corporate workstations, routing internal traffic through the host.
* **Nmap / Masscan Native Port Scanner:**
  * Asynchronous raw-socket SYN scanner embedded directly into the host engine to sweep local `/24` subnets in seconds and fingerprint open ports, banners, and operating systems.
* **RouterSploit & Embedded IoT Exploitation:**
  * Automated testing of connected gateway routers for default credentials (admin/admin), unauthenticated CGI execution, and outdated firmware vulnerabilities.
* **SSLsplit / SSLstrip+ Engine:**
  * Intercepts transparent traffic, strips HTTPS redirect headers, converts secure links into unencrypted HTTP mirrors, and captures plaintext login sessions.

### 2. Defensive Network Tools
* **Zeek (Bro) / Suricata-Mobile IDS:**
  * Real-time packet parsing engine analyzing HTTP/TLS headers, detecting beaconing frequencies characteristic of C2 malware, and inspecting DNS query entropy (detecting DNS tunneling).
* **JA3 / JA4 TLS Fingerprint Radar:**
  * Evaluates TLS Client Hello parameters (ciphers, extensions, elliptic curves) against malicious JA3 databases to detect unauthorized background spyware connecting out.
* **Canary Token & Honey-Port Trap:**
  * Opens silent dummy TCP/UDP ports on the host. Any unauthorized inbound connection attempt (from network scanners like Shodan or internal adversaries) triggers an immediate Defcon-1 alert in the Admin HUD.
* **ARP Poisoning & DNS Tamper Guard:**
  * Periodically cross-validates the gateway MAC against `/proc/net/arp` and queries authoritative root DNS over DoH/DoT to detect rogue captive portals or local ARP spoofing.

## III. Binary Exploitation, Reverse Engineering & Hooking (RE/VR)

### 1. Offensive RE & Hooking Tools
* **Embedded Frida Gadget & Agent:**
  * Injects JavaScript scripts dynamically into target Android processes to hook native JNI methods, intercept Java crypto classes (`Cipher.doFinal`), and bypass certificate pinning.
* **Smali / Dex Decompiler & Patching Engine:**
  * Automates pulling target APKs, disassembling via Smali/Baksmali, patching target bytecode (e.g., bypassing license checks or authentication guards), and re-signing on device.
* **Radare2 / Cutter Mobile Disassembler:**
  * Native ARM64 disassembler to inspect in-memory `.so` libraries, search for ROP (Return-Oriented Programming) gadgets, and trace execution flow.
* **Memory Dump & String Scraper:**
  * Scans `/proc/[pid]/mem` of target messaging or banking applications to carve plaintext passwords, session tokens, and unencrypted cryptographic keys from RAM.

### 2. Defensive Anti-RE & Binary Integrity Tools
* **Anti-Frida & D-Bus / GumJS Sentinel:**
  * Scans memory maps for `frida-agent.so`, monitors D-Bus socket handles, checks thread names for `gmain`/`gum-js-loop`, and verifies `ptrace` tracer status.
* **Anti-Xposed & LSPosed Armor:**
  * Detects modified classloaders, checks method reflection modifiers, and verifies that `art::ArtMethod` function pointers point inside read-only `libart.so`.
* **Kernel Syscall Hook Detector:**
  * Verifies that the ARM64 Exception Vector Table (`VBAR_EL1`) and libc syscall stubs contain untouched `svc #0` opcodes without inline jumps (`b` or `ldr pc`).
* **In-Memory .text Checksum Verifier:**
  * Computes continuous Blake3 hashes of the running executable code section to defeat runtime debugger breakpoint patches (`0xD4200000` `BRK` instructions).

## IV. OSINT, Social Engineering & Credential Harvesting

### 1. Offensive OSINT Tools
* **Sherlock & Maigret Mobile Scanner:**
  * Queries hundreds of social networks, developer hubs, and forums simultaneously using a target username to build a live dossier of the subject.
* **PhoneInfoga & Carrier Intelligence:**
  * Queries international telecom databases, HLR lookups, and risk scoring for target phone numbers directly from the Admin Tactical HUD.
* **Phishlet & Decoy System Update Prompt:**
  * Presents native-looking system update or biometric re-authentication prompts to capture device passcodes or enterprise Google/Microsoft credentials.
* **Deep Data Harvester:**
  * In unmanaged/rooted contexts, parses WhatsApp SQLite databases (`msgstore.db`), Telegram local cache, browser autofill histories, and stored Wi-Fi credentials (`wpa_supplicant.conf`).

### 2. Defensive OSINT & Privacy Protections
* **Data Breach & Pwned Account Monitor:**
  * Proactively monitors enterprise emails and phone numbers against known dark-web credential dumps via secure k-anonymity API queries.
* **Camera & Mic Physical LED / Sensor Auditor:**
  * Queries low-level camera HAL and audio server states to alert if background applications access hardware sensors without lighting the OS privacy indicators.
* **Clipboard Sentinel:**
  * Monitors Android system clipboard for unauthorized reads of cryptographic private keys, seed phrases, or one-time passwords (OTPs).

## V. Digital Forensics & Anti-Forensic Countermeasures

### 1. Offensive Forensic Acquisition
* **Physical NAND Bit-Stream Imaging (dd / LiME):**
  * Raw extraction of physical partition blocks (`/dev/block/by-name/userdata`) or volatile RAM dump via Linux Memory Extractor kernel modules for offline Autopsy analysis.
* **Deleted SQLite Database Carving:**
  * Scans database WAL (Write-Ahead Log) files and unallocated storage blocks to recover deleted SMS, call records, and location logs.

### 2. Defensive Anti-Forensics & Counter-Seizure
* **Cellebrite / GrayKey UFED Lockdown:**
  * Detects physical forensic extraction hardware or unfamiliar USB OTG controllers connected while the device is locked.
  * Enforces an immediate USB data bus disconnection, locks encryption keys in RAM, or forces an instant system power down.
* **Duress Code & Plausible Deniability Wipe:**
  * Secondary panic passcode that unlocks a decoy Android profile while silently and irreversibly shredding user encryption keys (`/data/misc/keystore/`).
* **Cold-Boot RAM Scrubber:**
  * Overwrites volatile memory buffers with high-entropy random noise prior to shutdown to prevent cryogenic cold-boot RAM attacks.
